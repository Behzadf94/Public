## ۱. نمای کلی و فلسفه طراحی (Architecture Overview)

پروژه **BFNETADMIN** یک جعبه‌ابزار پیشرفته، ماژولار و سبک‌وزن برای مدیران شبکه، مهندسان امنیت و سامانه‌ها است. این نرم‌افزار با رعایت اصول **Clean Architecture** و الگوی رفتاری **Command Pattern** طراحی شده است تا تمام درخواست‌ها و عملیات‌ها از رابط کاربری (UI) مجزا بوده و امکان اجرای توزیع‌شده (از طریق CLI یا Agent سوکتی) را بدون تغییر در هسته نرم‌افزار فراهم سازد.

## ۲. فهرست تفصیلی قابلیت‌ها و امکانات (Key Features)

### الف) رابط کاربری با تم تیره و استایل هکری (Hacker / Cyber Dark Theme)
* **پالت رنگی اختصاصی Cyberpunk/Matrix:** رابط گرافیکی طراحی‌شده با پس‌زمینه تیره عمیق (`#0d1117` و `#161b22`) همراه با تایپوگرافی سبز نئونی/ماتریکسی (`#00ff66` و `#3fb950`) جهت کاهش خستگی چشم در شیفت‌های شب و اتاق‌های NOC/SOC.
* **استایلینگ بومی `ttk.Style`:** بازطراحی کامل کامپوننت‌های فرم، تب‌ها (Notebook)، جدول‌ها (Treeview)، کلیدهای عملیاتی و فیلدهای متنی بدون وابستگی به فریم‌ورک‌های سنگین خارجی.
* **جدول‌های با کنتراست بالا (Cyber Grid):** شخصی‌سازی ردیف‌ها و هدرهای جداول پویش شبکه و تست DNS با خطوط تفکیک‌کننده، فونت‌های مونو و پس‌زمینه های‌لایت‌شده هنگام انتخاب سطر.

### ب) اسکنر هوشمند شبکه (IP & Port Scanner)
* **اسکن بازه‌ای بدون وابستگی به ابزار خارجی:** توانایی اسکن بازه‌های دلخواه IPv4 (مانند `192.168.1.1` تا `192.168.1.254`) صرفاً با سوکت‌های بومی پایتون و بدون نیاز به نصب کتابخانه‌هایی چون Nmap.
* **ارزیابی پرسرعت و هم‌روند (Multi-Threaded):** بهره‌گیری از `ThreadPoolExecutor` با ۵۰ Worker هم‌زمان جهت اسکن سریع زیرشبکه‌ها بدون فریز شدن رابط کاربری.
* **شناسایی پورت‌های حیاتی سازمان:** پایش خودکار پورت‌های کلیدی شامل:
  * وب: HTTP (80)، HTTPS (443)، پورت‌های جایگزین (8080)
  * اشتراک فایل و کنترل از راه دور: SMB (445)، RDP (3389)، RPC (135)، NetBIOS (139)
  * مدیریت و انتقال داده: SSH (22)، FTP (21)، Telnet (23)
* **استخراج نام میزبان (Reverse DNS Resolution):** تشخیص و درج نام سیستمی (`Hostname`) کلاینت‌های روشن در شبکه.

### ج) بنچمارک و بهینه‌سازی ترکیبی سامانه نام دامنه (DNS Benchmark & Hybrid Optimization)
* **بانک جامع سرورهای DNS:** تست هم‌زمان ۵۰ سرور DNS تفکیک‌شده:
  * **سرورهای ملی و تحریم‌شکن داخلی (IR):** شکن، رادار گیم، الکترو، ۴۰۳ آنلاین، بگذر، آسیاتک، شاتل، پارس‌آنلاین، هاست‌ایران، زیرساخت (TIC) و همراه اول/مخابرات.
  * **سرورهای بین‌المللی با تأخیر پایین و امنیتی (INT):** Cloudflare، Google، Quad9، OpenDNS، AdGuard، CleanBrowsing، Control D، Comodo و Level3.
* **پایش واقعی زمان تأخیر (UDP Latency Probe):** ارسال پکت واقعی DNS Query روی پورت 53 UDP به جای استفاده از Ping ICMP (چرا که برخی سرورها ICMP را مسدود می‌کنند).
* **معماری DNS هیبریدی هوشمند (Smart Hybrid Resolver):**
  * الگوریتم سیستم سریع‌ترین DNS داخلی (جهت دور زدن تحریم‌ها و اتصال سریع به اینترانت) و سریع‌ترین DNS بین‌المللی را انتخاب می‌کند.
  * امکان اعمال آنی تنظیمات به عنوان Primary و Secondary روی کارت شبکه فعال ویندوز با یک کلیک (از طریق دستورات استاندارد `netsh`).

### د) مدیریت سیستم و امنیت کاربران (Active Directory / Windows Tools)
* **مدیریت محلی و تحت دامنه کاربران ویندوز:** ماژول ریست سریع کلمه عبور کاربران محلی یا سیستم‌های دامنه‌ای بدون نیاز به اجرای دستی کنسول `compmgmt.msc`.
* **رمزنگاری بصری ورودی:** ماسک‌سازی فیلد کلمه عبور جهت رعایت الزامات محرمانگی در حضور دیگران.

### هـ) پایداری وضعیت نرم‌افزار (Session Persistence)
* **حفظ تنظیمات ورودی (`app_state.json`):** نرم‌افزار آخرین مقادیر وارد شده برای IP شروع، IP پایان و نام کاربری را در زمان خروج ذخیره کرده و در اجرای بعدی به‌طور خودکار بازیابی می‌کند.

### و) زیرساخت ممیزی و وقایع‌نگاری (Audit & Compliance Logging)
* **پایگاه‌داده محلی رویدادها (`bfnetadmin_audit.db`):** کلیه عملیات‌های اسکن، بنچمارک، تغییر DNS و تغییر کلمه عبور به همراه زمان دقیق، وضعیت (Success/Failed) و شناسه مبدأ در پایگاه‌داده SQLite ثبت می‌شوند.
* **ایمنی در برابر هم‌زمانی (Thread-Safe):** استفاده از قفل نرم‌افزاری (`threading.Lock`) برای جلوگیری از تداخل تراکنش‌های دیتابیس در محیط‌های چندنخی.

### ز) امکان مدیریت از راه دور (Remote Agent Server)
* **اجرای کلاینت/سرور (`remote_agent.py`):** توانایی راه‌اندازی سرور روی پورت `9999` جهت دریافت دستورات شبکه به فرمت JSON و اجرای توزیع‌شده فرمان‌ها روی سرورها و شعب دیگر.

## ۳. نقشه ساختار فایل‌ها (Project Structure)

| نام فایل | نقش و مسئولیت در معماری |
| :--- | :--- |
| **`base_command.py`** | تعریف کلاس پایه مجرد (`BaseCommand`) و قرارداد استاندارد تبادل فرمان‌ها |
| **`command_registry.py`** | سیستم ثبت مرکزی (Registry) و توزیع‌کننده داینامیک فرمان‌ها با Lazy-Loading |
| **`scanner.py`** | منطق پویش آی‌پی‌ها، اعتبارسنجی سوکت‌ها و تشخیص سرویس‌های فعال |
| **`network_utils.py`** | پیاده‌سازی بنچمارک ۵۰ سرور DNS، استخراج کارت شبکه فعال و تنظیم DNS ویندوز |
| **`ad_manager.py`** | ماژول عملیات مدیریتی سیستم و ریست کلمه عبور حساب‌های کاربری |
| **`db_core.py`** | موتور لاگ‌گذاری رویدادها در پایگاه‌داده SQLite به صورت Thread-Safe |
| **`remote_agent.py`** | سرور سبک سوکتی برای کنترل و اجرای ریموت دستورات تحت بستر شبکه |
| **`main.py`** | رابط کاربری گرافیکی مدرن با تم تیره/هکری بر پایه `tkinter/ttk` با قابلیت گزارش‌گیری زنده پیشرفت |
| **`deploy_patch.py`** | اسکریپت استقرار خودکار و بی‌نقص فایل‌های فوق با کدگذاری `UTF-8` |
| **`apply_patch.bat`** | اسکریپت راه‌انداز تک‌کلیکی جهت استقرار و اجرای امن سامانه |
